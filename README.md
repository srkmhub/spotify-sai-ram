# Tunely – Spotify-Inspired Website (DevCamp 2.0, Task 1)

A multi-page static website built with **HTML5 and CSS3 only** (no JavaScript, no frameworks).

## Pages
- `index.html` – Home (navbar, hero, signup form, featured playlists, footer)
- `browse.html` – Browse all (Pop, Hip-Hop, Chill, Workout genre cards)
- `playlist.html` – Playlist details (cover, description, track table, Play button)

## Concepts used
Semantic tags, external `style.css`, reusable classes, one ID selector (`#hero`), Flexbox, CSS Grid, box model, colours `#1DB954` and `#191414`, hover effects, responsive layout.

## Notes
The signup form and Play button are visual demos only. Cover art is original SVG artwork in `assets/`. This is a student project and is not affiliated with Spotify.
